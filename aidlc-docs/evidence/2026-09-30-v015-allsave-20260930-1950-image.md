## 4. 本次发现的既有缺口：`build_app` 被跳过，Wi-Fi **用户态**未入镜像（**非本次回归**）

> 这是本次核验新记录的事实，**不是**本切片引入的回归；两个 V015 候选逐项相同。**未修改任何源码。**

- 构建日志 1778 行：
  `[build.sh:info] Skipping build_app for missing configs:  LF_WIFI_PSK LF_WIFI_SSID.`
- 机制（`project/build.sh:636-666`）：`build_app()` 在 `RK_ENABLE_WIFI=y` 时先 `check_config LF_WIFI_PSK LF_WIFI_SSID || return 0`，
  凭据缺失即**整段 `build_app` 提前返回**（后续 `make -C project/app` 不执行）。
- 直接后果：V015 BoardConfig 头部注释声明"镜像不预置 Wi-Fi 凭据，由设备端受控配网"，
  但 `build_app` 的早退**同时**跳过了 `project/app/wifi_app/Makefile` 的全部用户态安装，导致 **rootfs/oem 均无**：
  - `/usr/bin/rkwifi_server`（Wi-Fi 控制守护进程，`insmod_wifi.sh` 末尾 `rkwifi_server start` 依赖它）、
  - `/usr/bin/wpa_supplicant`、`/usr/bin/wpa_cli*`、`/usr/bin/wpa_supplicant_rtk`、`/usr/lib/libwpa_client.so`、
  - `/usr/lib/librkwifibt.so`、`/usr/bin/hostapd`、`/etc/wpa_supplicant.conf`。
- **内核侧未受影响（在镜像内）**：`oem/usr/ko/` 含 `aic8800_bsp.ko / aic8800_fdrv.ko / aic8800_btlpm.ko`、
  `insmod_wifi.sh`、`insmod_ko.sh` 与 `aic8800dc_fw/`；`S35wifibt` 的 `wait_oem_ko`/`insmod_wifi.sh` 可正常加载。
  即 **Wi-Fi 内核驱动与固件可加载，但缺用户态控制/配网程序** ⇒ 即便上板，`rkwifi_server`、
  `wpa_supplicant` 均不存在，受控配网流程**无法成立**。
- 证据边界：
  - 这是**包内静态事实**（debugfs 在两个候选 rootfs/oem 上同名均可复现 absent），非实机现象。
  - 与本分支 `CURRENT.md` §4"无网络首启：镜像不预置 Wi-Fi 凭据是刻意决定，但'设备端受控配网'流程未验证"
    一致，但**该记录未指出 `build_app` 连带跳过用户态二进制**这一后果。
- **处置建议（超出本切片授权范围，未执行）**：本切片仅授权"构建 + 静态核验 + 证据"，
