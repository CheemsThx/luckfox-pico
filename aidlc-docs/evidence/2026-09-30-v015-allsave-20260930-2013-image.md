## 3. 包内静态核验（双层解包）

### 3.1 板型与分区

- `tools/linux/Linux_Pack_Firmware/rkImageMaker -unpack`（v2.2，**退出码 0**）→ `boot.bin`(268,736) + `firmware.img`；
  `tools/linux/Linux_Pack_Firmware/afptool -unpack`（v2.2，**退出码 0**）→ `Image/{env,idblock,uboot,boot,oem,userdata,rootfs}.img` + `package-file` + `download.bin`。
- `RKFW` 头芯片串含 `6011`（RV1106）。
- `package-file` 分区清单：`env / idblock / uboot / boot / oem / userdata / rootfs`（+ `package-file`、`bootloader=download.bin`）。
- `env.img` 内：`blkdevparts=mmcblk0:32K(env),512K@32K(idblock),256K(uboot),32M(boot),512M(oem),256M(userdata),6G(rootfs)`。
- 解包出的 7 个分区镜像与候选 `IMAGES/` 同名文件**逐一 SHA-256 一致**（boot/rootfs/oem/userdata/uboot/idblock/env 全 MATCH）。
- 分区尺寸与声明边界（实际大小 ≤ 声明）：

### 3.2 包内 DTB 与内核配置

对实际打包的 FIT `fdt`（`/tmp/fit2013.dtb`，`e3b00deb…`）反编译：

- `model = "Dongwei DW-TLY-V015 eMMC"`。
- Wi-Fi SDIO `mmc@ffaa0000`：`bus-width = <0x04>`、`non-removable`、`supports-sdio`、`max-frequency = <0x2faf080>`(50 MHz)。
- eMMC `bus-width = <0x08>`、`non-removable`。
- `compatible = "rockchip,rv1106-ioc\0syscon"`（grf 匹配键在镜像内）。
